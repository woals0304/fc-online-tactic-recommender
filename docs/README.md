# 프로젝트 문서 안내

이 디렉터리는 FC ONLINE 전술 추천기의 제품·연구·검증 기준을 관리합니다.

| 문서 | 용도 |
| --- | --- |

| [논문 적용 및 추천 효과 검증 로드맵](research-validation-roadmap.md) | 축구 분석·추천 시스템 논문의 적용 범위, 필요한 데이터, 실험과 평가 방법, 단계별 개발 순서 |
| [실사용 테스트 기록 양식](user-test-record-template.md) | 한 번의 추천 결정과 적용 전후 결과, 사용자 평가를 일관된 형식으로 기록하는 양식 |
| [NEXON Open API 데이터 처리 기준](data-handling-policy.md) | 30일 TTL, 가명 처리, 삭제·철회, 캡처와 합성 fixture, 운영 배포 게이트 |

## 문서 사용 원칙

- 팀 전술의 공식 입력 범위와 개인 전술의 검증 경계는 `fc-online-tactic-schema.md`를 기준으로 합니다. 개인 전술 후보와 참여도는 현행 클라이언트에서 추가 검증합니다.
- 현재 코드는 팀 전술 입력 계약을 자동 검증하지만 포메이션과 개인 전술은 미확인입니다. 전체 결과를 완전한 인게임 호환으로 간주하지 않습니다.
- 논문의 실제 축구 수치나 모델을 FC ONLINE에 그대로 이식하지 않습니다. 데이터 구조와 평가 방법만 참고하고 FC ONLINE 데이터로 다시 검증합니다.
- 추천 적용 전후의 단순 차이를 추천의 인과 효과로 표현하지 않습니다.
- FC ONLINE 패치로 전술 의미나 선택지가 바뀌면 검증 날짜와 전술 스키마 버전을 함께 갱신합니다.
- API 원본과 파생 데이터는 `data-handling-policy.md`에 따라 최대 30일 TTL과 삭제·철회 절차를 적용하며, 공개 저장소에는 합성 fixture만 둡니다.
