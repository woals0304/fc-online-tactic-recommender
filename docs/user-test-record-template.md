# FC ONLINE 추천 전술 실사용 테스트 기록

이 양식은 한 번의 추천 결정, 인게임 이식 여부, 실제 적용과 전후 결과를 일관되게 기록하기 위한 것입니다.

소수 경기 테스트는 기능·이식성 스모크 테스트입니다. 단순한 적용 전후 차이를 추천의 인과 효과로 해석하지 않습니다. 효과 검증 원칙은 [논문 적용 및 추천 효과 검증 로드맵](research-validation-roadmap.md)을 따릅니다.

- 후보 전술 ID 목록:

- 로깅 정책 ID와 버전:

- 사용자가 화면에서 추천을 확인했는가:
- 사용자가 지정 전술을 선택했는가:
- 실제 처치 `actually_applied_tactic_id` 또는 설정 해시:

무작위 실험이 아니라면 지정 확률에 `해당 없음`을 기록하고 사후에 확률을 만들어 넣지 않습니다.

두 후보를 모두 보여주고 하나를 먼저 지정했다면 무작위화된 처치는 실제 사용 전술이 아니라 `지정·강조`입니다. 주 분석은 미적용·변경 사례를 포함한 `assigned_tactic_id` 기준 ITT로 수행합니다. 별도 비순응 식별 설계가 없으면 실제 적용 전술의 결과는 연관성으로만 기록합니다.

## 13. 개인 정보와 공개 범위

- 실제 닉네임, OUID, API 키, 실제 matchId와 원본 경기 응답을 공개 문서에 첨부하지 않습니다.
- 장기간 연결되는 사용자·경기 참조는 `익명`이 아니라 `가명`으로 표시합니다. 실제 식별자와의 매핑표는 접근을 제한하고 같은 삭제 기한을 적용합니다.
- 모든 API 원천·파생 레코드에 `pulled_at`과 최대 30일 이내의 `expires_at`을 기록하고, 만료 시 원본·집계·로그·캐시·백업에서 삭제하거나 API로 다시 조회합니다.
- 삭제·동의 철회 요청이 오면 해당 사용자의 원본, 가명 매핑, 파생값과 사본을 함께 삭제합니다.
- 실제 응답이 필요하면 로컬 `captured` 영역에만 임시 보관하고 Git에 추가하지 않습니다. 현재 자동 삭제가 없으므로 30일 이내 직접 삭제합니다.
- 공개 재현 자료에는 실제 응답을 단순 가명 처리한 값이 아니라 사람이 구성한 합성 fixture만 사용합니다.
- 외부 사용자 대상 운영 전에는 실제 처리와 일치하는 개인정보처리방침과 열람·정정·삭제·철회 접점을 제공합니다.
- 스크린샷에는 계정 식별 정보와 대화·알림 등 불필요한 개인 정보를 가립니다.

전체 수명주기는 [NEXON Open API 데이터 처리 기준](data-handling-policy.md)을 따르며, [NEXON Open API 이용약관](https://openapi.nexon.com/support/)의 최신 내용이 우선합니다.
